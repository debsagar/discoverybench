# Smart vs random experiments

Give two players the same world, the same watching time, and the same reasoning
engine. One picks experiments at random. The other picks them on purpose.

Count how many experiments each needs before only one story is left.

That ratio is the whole benchmark. If random pokes get there almost as fast as
chosen ones, the world is not testing thought, it is testing luck. If chosen
pokes get there in a few and random never does, the world rewards design.

The ratio belongs to the world plus the rules of poking, not to any player.
