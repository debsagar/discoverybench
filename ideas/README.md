# ideas

Loose intuitions, one file each. Nothing here is a decision, a plan, or a claim
the code has to honour. Write an idea down here so it survives without having to
fit the current design; promote it to `wmi/docs/plans` or the project log only
when it earns a test.

Rules: one idea per file, dated filename (`YYYY-MM-DD-slug.md`), no cross-references
required, no need to reconcile with other ideas or with the codebase.
