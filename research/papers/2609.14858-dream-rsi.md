# Dream-RSI: Recursive Self-Improvement through Evolving Worlds

arXiv 2609.14858, 14 Sep 2026. Google, Google DeepMind, UMD, UVA.
PDF: 2609.14858-dream-rsi.pdf. Repo: https://github.com/zhengkid/Dream-RSI (paper only, code not released yet). Site: https://dream-rsi.com

## How the environment is made

1. A coding agent works on a hard task. Every attempt is saved as a node in a tree: parent, workspace snapshot, the program it wrote, the evaluator's notes, a score. Root = empty workspace.
2. A separate small program, the exploration policy, decides each round which nodes to continue from: open a new branch at the root, or extend the tip of an open branch. Up to W picks per round, one per parallel worker.
3. When the run ends, the finished tree is frozen. That frozen tree IS the environment.
4. Replay: a new policy starts seeing only the root. When it picks a node, the world reveals that node's recorded child. Picking the root reveals the next unopened branch, in the order they were first made. Nothing new is generated, every outcome is read from disk.
5. Replay stops when the policy picks nothing, a round limit hits, or the whole tree is revealed.
6. Score per tree: best score revealed, minus a cost per node revealed, plus a bonus for nodes per round (rewards batching). Averaged over all stored trees.
7. An LLM reads the replay traces and rewrites the policy code. M revisions, keep the best, which always includes the current one so it never gets worse on the stored trees.
8. The winning policy runs online once, makes a new tree, the pool of worlds grows. Repeat.

## What the policy can and cannot do in replay

It can only reorder, regroup and stop early along paths that were actually taken. A branch is always walked in its recorded order. Asking for more branches or depth than the recording holds earns nothing. So the world is exact but only as wide as the history.

## Reported result

Lasso solver design: 317 agent calls versus 51,200 for the SimpleTES baseline, similar quality. Also tested on maths optimisation and GPU kernels.
