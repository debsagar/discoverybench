# Twist Axis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make "what drives the hidden variable" a sampled world parameter, so the benchmark has several distinct, certifiable ahas inside ONE world family, and add the analytic study that decides which twists earn a place.

**Architecture:** Every twist is the same machine `h' = m[h, d_t]` with a different binary *driver signal* `d_t`. One module (`drivers.py`) computes `d_t` for both the simulator (ground truth) and the theorist (hypothesis), so the two can never drift apart. The theorist is unified into `theorist.py` (gate_a and gate_a2 currently carry duplicate copies), parameterised by driver. A study script (`twists.py`) computes the two analytic selection criteria: certifiability rate and the class-distinctness matrix.

**Tech Stack:** Python 3, numpy 2.x (`np.bitwise_count`), pytest 9 for the test file. No new dependencies.

**Spec:** this document (sections "Math" and "Boundaries" are the spec).

## Math (what the twists are)

State per cell: visible `v ∈ {0,1}`, hidden `h ∈ {0..H−1}`. Update, all cells synchronous:

```
count_t   = Σ_{8 Moore neighbours} v_t
v_{t+1}   = survive[h_t][count_t] if v_t = 1 else birth[h_t][count_t]
h_{t+1}   = m[h_t][d_t]                      m : (H,2) → H   (the "machine")
```

The twist is the driver `d_t ∈ {0,1}`:

| driver | `d_t` | aha | h reconstructible from |
|---|---|---|---|
| `own` (baseline) | `v_t` (own cell) | cells remember their own past | own visible history |
| `count(τ)` | `1{count_t ≥ τ}` | cells remember their crowd | 3×3 history |
| `clock(T)` | `1{(t+1) mod T = 0}` | rule changes with time, globally | t alone |

Second axis, orthogonal: `h0`. `zero`: h₀=0 everywhere (reconstruction). `random`: h₀ ~ Uniform{0..H−1} per cell, hidden (inference: the agent must *filter* h₀ from behaviour).

**Redundancy by construction.** A delay-d world (`v_{t+1}` selects its table by `v_{t−d}`) is `own` with a shift-register machine, H = 2^d. It is already inside the `own` class, so it is NOT a separate twist. This is the first analytic result of the study and costs nothing.

**Description length** (bits): tables `18·H` + machine `2H·log₂H` + driver id `log₂(#drivers)` + param `3`.

**Criterion 1 — certifiability rate.** For twist X, sample N worlds, run `certify` with the theorist given the true class. Rate = #CERTIFIED / N. A twist whose worlds are mostly SWEEPABLE or REJECT is out. The enumerator family gains a `t`-keyed table (feature = pattern | t<<9), because for `clock` that is the strongest cheap null and omitting it would certify dishonestly.

**Criterion 2 — distinctness matrix.** `D[i][j]` = held-out error of the theorist restricted to class i, on CERTIFIED worlds of class j, at the certification budget. Diagonal ≈ 0 by certification. Off-diagonal high ⇒ classes are different ahas. Off-diagonal ≈ diagonal ⇒ redundant twist. Row `own` on column `j` is precisely what an agent that "knows the baseline trick" scores: the memorisation control.

**Criterion 3 (not built here)** — identification budget via greedy expected information gain over the class union. Built only if the matrix is clean.
